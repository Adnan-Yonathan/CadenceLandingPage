Common fixes

  • Apps are not locking: In iOS Settings, confirm Cadence still has Screen Time / Family Controls authorization and that the apps or categories are selected in Cadence.
  • Run distance is not updating: Allow Precise Location and Always Location for Cadence while using an active Run Alarm. Also confirm Motion & Fitness access is enabled.
  • The alarm or reminder did not appear: Check Cadence notification and alarm permissions, Focus settings, device volume, and Low Power Mode.
  • Purchase is not recognized: Open Cadence Pro in the app and use Restore Purchases. For web purchases, open the redemption link sent after checkout using the same iPhone.
  • Strava will not sync: Disconnect and reconnect Strava, then confirm Cadence has the requested Strava permissions.
